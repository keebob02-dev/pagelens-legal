## 1. What StackAudit does

StackAudit is a Shopify-embedded app that:
- Scans your public storefront homepage and identifies what scripts and resources are loading
- Attributes each script to its likely owning app
- Runs Google PageSpeed Insights against your storefront and surfaces the results
- Inspects your active theme's files to detect "ghost code" left behind by previously-uninstalled apps
- Detects `<img>` tags missing `loading="lazy"` in below-the-fold templates
- On paid tiers: deletes ghost files from your theme on your explicit per-file click

## 3. The auto-fix feature

- The auto-fix ("Fix it") feature **only deletes files we've flagged as ghost code from previously-uninstalled apps**.
- Every deletion requires your explicit per-file confirmation.
- StackAudit refuses to delete any file that isn't on the current scan's ghost-finding list — even if asked to via a manipulated request.
- We cannot guarantee that every detected ghost file is safely deletable. Some merchants modify theme files manually in ways our detector cannot distinguish from leftover code. **If you're not sure, click "Open in theme editor" instead of "Fix it"** and inspect the file yourself.
- If you delete a file via "Fix it" that you regret, you can restore it from Shopify's theme editor file-revision history.
